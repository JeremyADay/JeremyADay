### Hi, I'm Jeremy

I work in lab automation, mostly on Hamilton STAR and STARlet liquid handlers running Venus. When something in that work is slow or hard to check, I tend to build a small tool for it.

**Lab automation**

- [Hamilton LC Explorer](https://github.com/JeremyADay/hamilton-lc-explorer): search Venus liquid class databases and compare them across instruments to catch parameter drift.
- [Hamilton LC Explorer for Mac](https://github.com/JeremyADay/hamilton-lc-explorer-mac): the same tool as a single browser file that reads `.mdb` liquid class databases directly.
- [Channel Alignment Analyzer](https://github.com/JeremyADay/hamilton-alignment-analyzer): checks STAR and STARlet channel stop-disk alignment from a photo, entirely in the browser.

**Other things I've made**

- Koi pond, a world I contributed to [Deskworlds](https://github.com/chaseleantj/deskworlds), live wallpapers for the Mac.
- A [Klipper setup](https://github.com/JeremyADay/Ender3_Klipper_Plotter) that turns an Ender 3 into a pen plotter, and parametric OpenSCAD designs for 3D printing.
